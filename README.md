(1) GitHub Pages 與 PWA 安裝
在電腦與手機使用 Chrome / Edge (iphone需用Bluefy或BLE Link) 開啟上述網址，點選網址列右側「安裝應用程式」即可安裝至桌面離線開啟WEBAPP。

(2) 以 WebApp+USB 更新 cubiio
以 Micro-USB 連接 Cubiio跟"電腦"，在 WebApp 進入[維護] → [韌體更新]， 選擇 COM 埠與 `cubiio_re_V1.6.ino.hex` 即可燒錄。

(3) 實際操作 
cubiio需接5V/2A的電源，用Chrome / Edge  開啟桌面WEBAPP，點選BLE連線開始操作。
